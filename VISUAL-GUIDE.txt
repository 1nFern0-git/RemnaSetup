🛡️ Резервные копии создаются ВСЕГДА перед патчингом

📁 Найти бэкапы:
   ls -la /opt/remnanode/docker-compose.yml.backup-*

🔄 Откатить изменения:
   sudo cp /opt/remnanode/docker-compose.yml.backup-20250115-030001 \
           /opt/remnanode/docker-compose.yml
   cd /opt/remnanode
   sudo docker compose down
   sudo docker compose up -d

📋 Проверить текущую конфигурацию:
   cat /opt/remnanode/docker-compose.yml | grep -A2 "volumes:"
